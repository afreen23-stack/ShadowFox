Data Visualization using Matplotlib & Seaborn

This project demonstrates various types of data visualizations using the Matplotlib and Seaborn libraries in Python. It includes code examples, graph outputs, and short descriptions for each type of plot.

What’s Inside: 
Matplotlib Plots -
3D Surface Plot
Polar Plot
Pie Chart
Error Bar Plot
Stacked Bar Plot

Seaborn Plots -
Heatmap 
Violin Plot 
Pair Plot  
Swarm Plot  
Boxen Plot  

Each example in the report contains:
A short explanation of the plot
Python code
Output screenshot
Description of the graph
